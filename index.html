Coze 配置说明

为保护密钥，生产环境配置由 Sites 服务端环境变量管理，浏览器不会保存 API Token。
COZE_API_TOKEN
Coze 个人访问令牌（必填，设为 Secret）
COZE_WORKFLOW_ID
已发布工作流 ID（必填）
COZE_API_BASE
默认 https://api.coze.cn；国际区可改为 https://api.coze.com

工作流输入：topic、product、channel、count。输出可为 JSON 数组，或包含 items / copies / results 的对象。
